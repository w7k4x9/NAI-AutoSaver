# NAI 자동저장 v1.10.1

NovelAI 이미지 생성 페이지(`https://novelai.net/image`)에서 사용하는 Chrome Manifest V3 확장 프로그램입니다.
자동 생성, 이미지 자동 저장(WebP·PNG), 대기열, 조합 생성, 프롬프트 메모, 보관함(검색·메타데이터 지운 사본·검열 사본·노션 연결)을 지원합니다.

## 주요 기능

- **자동 생성**: 지정한 횟수와 주기에 따라 NovelAI의 Generate 버튼을 자동 실행
- **이미지 자동 저장**: 생성이 완료될 때마다 결과 이미지를 자동 다운로드. 파일 형식은 **자동**(NovelAI에서 직접 받은 형식을 따라감) · WebP · PNG 중에서 고르며, WebP는 NovelAI와 똑같은 방식(무손실 + EXIF + 숨은 정보)으로 저장
- **저장 이름 관리**: `1_b_c`를 입력하면 `1_b_c (1).webp`, `1_b_c (2).webp`처럼 순번을 붙여 저장
- **보관함**: 저장한 그림을 프롬프트로 검색, 캐릭터별 보기, 크게 보기, 셀렉(채택·보류·탈락·별점)과 같은 이름끼리 나란히 비교. 탐색기와 같은 방식으로 여러 장 고르기(클릭 · Ctrl/⌘ · Shift · 끌어서 상자)
- **공유용 사본**: 메타데이터(프롬프트·시드 같은 생성 정보)를 지운 사본, 하얀 빛으로 가린 검열 사본(붓·지우개·크기 조절, 여러 장은 한 장씩 또는 한 번에)
- **노션 연결(선택)**: 그림과 프롬프트를 내 노션 데이터베이스에 캐릭터·날짜·태그로 정리
- **태그 뜻**: 프롬프트 태그에 마우스를 올리면 한국어 뜻 표시
- **대기열**: 선택해서 여러 개 지우기, 캐릭터·배경별로 순서 묶기. 항목마다 저장 이름, Base Prompt, Base Undesired Content, 캐릭터 프롬프트, 캐릭터 Undesired Content, 생성 횟수를 따로 설정
- **공통 Base**: 대기열의 `공통 Base 사용`을 켜면 Base Prompt와 **Base 네거티브**를 모든 항목이 함께 사용 (네거티브를 비워 두면 항목별 값을 그대로 사용)
- **단축키 차단**: 패널 안에서 누른 키와 휠은 NovelAI에 전달되지 않습니다. WASD·방향키·`-`/`_` 같은 NovelAI 단축키 때문에 입력칸에 글자가 안 써지던 문제를 막습니다
- **프롬프트 메모**: 베이스 프롬프트·베이스 네거티브·캐릭터 태그·캐릭터 네거티브를 1개 이상 선택해 저장하고, 대기열 스타일 카드와 작업 드롭다운으로 관리
- **다중 캐릭터 편집 (블록 / `;;` 텍스트)**: `+ 캐릭터 추가`로 블록 단위 편집, 또는 `;; 텍스트로 입력` 버튼으로 기존처럼 한 칸에 `;;`로 구분해 입력. 블록 안에 `;;`를 치거나 붙여넣어도 자동으로 캐릭터가 나뉩니다
- **캐릭터 카드 자동 생성**: 필요한 수만큼 Add Character를 누르고 Female, Male, Other를 자동 선택
- **조합 생성기**: 캐릭터, 표정, 배경 조합을 자동으로 대기열 항목으로 생성. 파일 이름은 프리셋 또는 `{캐릭터}_{배경} {표정}`처럼 직접. 배경·표정은 각각 **모든 캐릭터 공통** 또는 캐릭터마다 따로
- **대기열 가져오기/내보내기**: JSON 형식 지원
- **맥 스타일 창**: 왼쪽 사이드바 + 다크/라이트/자동 모드, 빨강(접기)·노랑(작게)·초록(전체화면) 버튼, 가장자리·모서리를 끌어 크기 조절, 실행 상태 표시
- **안내(튜토리얼)**: 화면마다 따라 하며 배우는 안내. 왼쪽 아래 `안내`로 언제든 다시 보기, 건너뛰기 가능

## v1.9.5 — 창 · 아이콘 · 안내 정리

- **창**: 가장자리나 모서리를 끌어 크기를 바꿔요 (좁히면 메뉴가 아이콘만 남아요). 제목 줄을 두 번 누르면 화면 가득, 모서리를 두 번 누르면 원래 크기
- **떠 있는 버튼**: 불투명한 검정 → 뒤가 비치는 유리
- **아이콘**: 선 아이콘을 면(채움) 아이콘 한 가지로 통일 (패널 · 보관함 · 팝업)
- **팝업**: 알록달록한 배경 대신 애플 설정 화면처럼 차분한 회색 + 파란색 하나
- **알림 창**: 브라우저 기본 확인 창 대신 iOS 알림 창, 노션 연결 창은 iOS 시트(취소 · 제목 · 다음)
- **조합**: 표정 줄에 「모든 캐릭터 공통」 체크 — 배경처럼 표정 목록 하나를 모든 캐릭터가 같이 써요
- **보관함 안내**: 오른쪽 위 「안내」에서 하고 싶은 걸 고르면 실제 화면을 짚으며 알려 줘요 (처음 열면 자동으로)

## v1.9.4 — 스토어 버전으로 자동 이사

압축해제로 설치한 버전은 웹스토어 버전이 설치되면 알아서 비켜서요. NovelAI 페이지를 열면 예전 버전은 패널과 저장을 멈추고 "이 예전 버전 지우기" 화면을 띄워요. 메모·대기열·설정은 스토어 버전으로 자동으로 넘어가요.

## v1.7.0 변경 사항 — 노션 연동

보관함 왼쪽 아래 **노션 연동 → 연결하기** (또는 패널 설정 → 노션 연동 → 보관함에서 설정).

1. 「노션 연결 페이지 열기」 → **새 연결(내부)** 만들기 → **내부 연결 토큰** 복사 → 붙여 넣기 (토큰은 이 컴퓨터에만 저장)
2. 노션에서 그림을 모을 페이지를 열고 **••• → 연결 → 방금 만든 연결 추가** → 「다시 찾기」
3. 그 페이지를 고르면 **NAI 그림 보관함** 데이터베이스를 만들어 줘요 (이미 있는 데이터베이스를 고르면 필요한 칸만 더해요)

- **분류 칸**: 이름 · 캐릭터(선택) · 날짜 · 태그(프롬프트에서 품질 태그를 뺀 내용 태그 최대 12개) · 모델 · 시드 · 프롬프트 · 네거티브 · 그림 · 메타데이터(지움/남아 있음)
- **페이지 안**: 그림 + 베이스 · 캐릭터별 · 네거티브 프롬프트 + 시드·스텝·가이던스·크기·경로
- **보내기**: 그림 하나 → 「노션에」, 여러 장 → 「노션에 N장 보내기」. 보낸 그림은 「노션에서 보기 ↗」로 바뀌고 다시 보내지 않아요 (⋯ → 노션에 다시 보내기)
- **자동**: 노션 설정에서 「새로 저장되는 그림을 자동으로 보내기」
- **올릴 그림**: 기본은 메타 지운 사본 (프롬프트는 칸에 따로 들어가요). 원본으로 바꿀 수 있어요
- 노션 무료 플랜은 파일 하나에 5MB까지라, 더 큰 그림은 그림 없이 프롬프트만 올라가요
- 노션 접속 권한은 「연결」을 누를 때 한 번 물어봐요 (처음 설치할 때는 묻지 않아요)
- Notion API 2026-03-11 (데이터 소스 · 파일 업로드 API)

- 보관함 자세히 보기의 「메모로 · 대기열에」는 ⋯ 메뉴로 옮겼어요 (아래에는 노션에 · 검열 사본 · 메타 지운 사본)

## v1.6.0 변경 사항 — 검열 사본 (v1.9부터 하얀 빛 방식으로 바뀜)

보관함에서 그림을 고르고 **검열 사본**을 누르면, 유두·성기를 찾아서 흰 블러로 가린 사본을 만들어요.

- **미리 확인하고 저장**: 찾은 곳이 주황 상자로 보여요. 상자를 누르면 빼고/넣고, 그림 위를 **끌면 직접 추가**해요. 「결과 미리보기」로 어떻게 가려지는지 보고 저장해요
- 「유두도 가리기」 · 「가리는 세기」 설정은 기억해 둬요
- **여러 장 한꺼번에**: 여러 장을 고르면 「검열 사본 N장 만들기 (자동)」. 가릴 곳을 못 찾은 그림은 저장하지 않고 알려 줘요 (그런 그림은 하나씩 열어서 직접 가려 주세요)
- 저장 위치: `다운로드/NovelAI/_검열/날짜/` · 메타데이터도 같이 지워요
- **모델**: [deepghs/anime_censor_detection](https://huggingface.co/deepghs/anime_censor_detection) (`censor_detect_v1.0_s`, 애니 그림 전용, 모델 카드 라이선스 MIT · Ultralytics YOLOv8로 학습). 확장 프로그램에 들어 있지 않고, 처음 쓸 때 한 번(약 45MB) 내려받아 이 컴퓨터에 보관해요. 그림은 밖으로 보내지 않고 브라우저 안에서만 검사해요
- 실행 엔진: onnxruntime-web (MIT, `vendor/ort/LICENSE`)
- 자동 검출이 100%는 아니에요. 공유 전에 꼭 한 번 확인해 주세요

## v1.5.0 변경 사항 — 태그 한국어 뜻

- **태그에 마우스를 올리면 한국어 뜻**이 위에 떠요: NovelAI 프롬프트 입력칸, 패널의 입력칸, 보관함 프롬프트
  - 가중치·괄호를 써도 알아봐요: `{black hair}`, `[smile]`, `1.2::looking at viewer::`
  - `artist:이름` 은 "작가 ○○의 그림체"로 보여 줘요
- **내장 사전**: 자주 쓰는 Danbooru·NovelAI 태그 약 1,700개를 직접 번역해 넣었어요 (`data/tags-ko.json`)
- **사전에 없는 태그**는 크롬에 들어 있는 번역기로 번역해요 (내 컴퓨터 안에서 돌아가고 무료). 처음 한 번은 번역 모델을 내려받는데, 크롬이 클릭을 한 번 필요로 해서 화면을 아무 데나 한 번 누르면 시작돼요. 한 번 번역한 태그는 기억해 둬요
- 설정 → **태그 뜻** 에서 켜고 끌 수 있어요 (뜻 보기 / 자동 번역 따로)

## v1.4.0 변경 사항 — 보관함

패널 왼쪽 **보관함 ↗** (또는 확장 프로그램 아이콘 → 보관함 열기)를 누르면 새 탭에서 열려요.

- **자동으로 쌓여요**: 자동 저장한 그림은 저장되는 순간 보관함에 들어가요 (미리보기 + 프롬프트 + 실제 저장 경로)
- **예전 그림**: 왼쪽 아래 **NovelAI 폴더 연결** → 다운로드/NovelAI 폴더를 고르면 안에 있는 PNG를 전부 읽어 와요. 크롬이 다시 물어보면 「허락하기」만 누르면 돼요
- **아무 그림이나**: 창에 끌어 놓거나 「파일 열기…」로 열면 정보를 읽어요 (보관함에는 저장 안 함)
- **프롬프트 검색**: `교실 웃음` 처럼 여러 단어(모두 들어간 것), `-hat` 은 빼고, `"black hair"` 처럼 따옴표는 붙은 그대로
- **자세히 보기**: 베이스 · 캐릭터별 프롬프트와 네거티브, 시드 · 스텝 · 가이던스 · 샘플러 · 모델. 메타데이터가 있으면 주황, 지운 사본이면 초록으로 표시
- **메타 지운 사본**: 한 장 또는 여러 장(왼쪽 위 동그라미, ⌘/Ctrl·Shift+클릭, ⌘/Ctrl+A)을 골라 만들면 `다운로드/NovelAI/_메타없음/날짜/` 에 원래 이름으로 저장돼요
  - 글자 정보(tEXt/iTXt)와 그림 투명도에 숨은 정보(stealth)를 둘 다 지워요. 그림 픽셀은 그대로예요
  - 원본을 읽어야 해서 처음 한 번은 폴더 연결이 필요해요 (끌어 놓은 파일은 바로 돼요)
- **메모로 · 대기열에**: 그림의 프롬프트를 그대로 메모나 대기열 항목으로 만들어요 (NovelAI 탭이 열려 있으면 그 탭 패널로 바로 들어가요)
- 그림 파일 자체는 지우지 않아요. 「보관함에서 빼기」는 목록에서만 빼요

## 기본 사용법

### 자동 생성

1. NovelAI 이미지 페이지를 엽니다.
2. 오른쪽 아래의 NAI 자동저장 패널을 펼칩니다.
3. 저장 이름, 프롬프트, 횟수, 주기를 입력합니다.
4. **자동 생성 시작**을 누릅니다.

`횟수`가 `0`이면 중지할 때까지 계속 생성합니다.

### Base Prompt와 캐릭터 프롬프트

Base Prompt와 캐릭터 프롬프트는 서로 다른 입력칸입니다.

- 장면, 화풍, 품질, 배경 등 공통 태그 → **Base Prompt**
- 인물별 성별, 머리색, 눈색, 의상 등 → **캐릭터 프롬프트**

캐릭터 프롬프트를 Base Prompt에 직접 붙일 필요는 없습니다. 확장 프로그램이 각 Character 카드에 따로 입력합니다.

## 다중 캐릭터 입력법

### 한 명

```text
1girl, black hair, red eyes
```

### 여러 명

`+ 캐릭터 추가` 버튼을 누르면 캐릭터 블록이 하나 늘어납니다. 블록 하나가 NovelAI의 Character 카드 하나에 대응합니다.

```text
캐릭터 1
  캐릭터 프롬프트 : 1girl, black hair, red eyes
  캐릭터 네거티브 : bad hands, extra fingers

캐릭터 2
  캐릭터 프롬프트 : 1boy, white hair, blue eyes
  캐릭터 네거티브 : long hair
```

- 블록의 `↑` `↓`로 순서를 바꾸면 프롬프트와 네거티브가 함께 이동합니다.
- `✕`를 누르면 그 캐릭터의 프롬프트와 네거티브가 함께 삭제됩니다.
- 블록을 하나도 추가하지 않으면 현재 NovelAI의 캐릭터 카드를 그대로 사용합니다.
- 네거티브를 비워 두면 그 캐릭터의 Undesired Content를 비웁니다.

같은 편집 방식을 **자동 생성 · 대기열 항목 · 프롬프트 메모** 세 곳에서 모두 사용합니다.

### 구분 규칙

- **한 캐릭터 안의 태그 구분**: 쉼표 `,`
- **캐릭터와 캐릭터 구분**: 블록 (직접 입력하지 않습니다)
- 세로줄 `|`은 캐릭터 구분자로 사용하지 않습니다.

내부 저장 형식은 이전과 같은 `;;` 문자열이라, **예전 버전에서 저장한 대기열·메모·내보낸 JSON을 그대로 불러올 수 있습니다.** 불러오면 자동으로 블록으로 나뉘어 표시됩니다.

### 성별 자동 선택

각 캐릭터 블록의 성별 태그를 읽어 캐릭터 카드의 유형을 선택합니다.

- `1girl`, `girl`, `female`, `woman` → Female
- `1boy`, `boy`, `male`, `man` → Male
- 성별을 판단할 수 없는 경우 → Other

NovelAI는 Female/Male 카드 생성 후 `1girl` 또는 `1boy`를 화면에서 `girl,` 또는 `boy,`로 정규화해 표시할 수 있습니다. 이는 정상 동작입니다.

현재 버전은 이미 있는 캐릭터 카드를 재사용합니다. 카드 수가 남으면 뒤에서부터 정리하고, 모자라면 필요한 만큼만 추가합니다.

## 캐릭터 Undesired Content

캐릭터 네거티브는 각 캐릭터 블록 안의 **캐릭터 네거티브** 칸에 입력합니다.

- 첫 번째 블록 → Character 1의 Undesired Content
- 두 번째 블록 → Character 2의 Undesired Content
- 비워두면 기존 값을 유지합니다.

## 프롬프트 메모

패널 왼쪽의 **메모** 탭에서 다음 4개 항목을 저장할 수 있습니다.

- 베이스 프롬프트
- 베이스 네거티브
- 캐릭터 태그
- 캐릭터 네거티브

저장할 항목만 체크합니다. 하나만 체크하면 개별 메모, 네 개를 모두 체크하면 한 세트로 저장됩니다.

- **NAI 현재값 읽기**: NovelAI 페이지에 현재 입력된 4종 값을 메모 편집기로 가져옵니다.
- **자동생성 값 가져오기**: 자동생성 탭의 4종 입력값을 가져옵니다.
- **입력칸 불러오기**: 메모에 포함된 항목만 자동생성 탭에 채웁니다. 포함되지 않은 항목은 유지됩니다.
- **NAI 직접 적용**: 메모에 포함된 항목만 NovelAI 입력 영역에 바로 적용합니다.
- **수정 / 삭제**: 저장된 메모를 편집하거나 제거합니다.

메모는 확장 프로그램 저장소와 NovelAI 페이지 쪽 사본에 함께 저장됩니다. 확장 프로그램을 다시 깔아도 NovelAI 페이지를 열면 자동으로 돌아오고, 삭제·수정 전 버전은 휴지통에 30일 보관됩니다. 브라우저 데이터를 통째로 지우는 경우에 대비해 설정 → 백업의 자동 백업 파일을 켜 두세요(기본 켜짐).

## 대기열

1. **현재 프롬프트 추가**를 눌러 현재 설정을 대기열 항목으로 저장합니다.
2. 각 항목에서 다음 값을 개별 편집합니다.
   - 저장 이름
   - Base Prompt
   - Base Undesired Content
   - 캐릭터 프롬프트
   - 캐릭터 Undesired Content
   - 횟수
3. **대기열 실행**을 누르면 항목별 프롬프트를 적용하고 순서대로 생성·저장합니다.
4. 반복을 켜면 마지막 항목 이후 다시 첫 항목부터 실행합니다.

대기열의 저장 이름은 각 항목에 설정된 값이 사용됩니다. 자동 생성 화면의 단발 저장 이름과는 별개입니다.

## 조합 생성

캐릭터 × 표정 × 배경을 한 번에 대기열로 만듭니다.

1. **누구** 옆 `+` → 오른쪽 칸에 캐릭터 이름과 외형 태그
2. **어디서** 옆 `+` → 배경 이름과 태그 (모든 캐릭터가 같이 씀)
3. **표정** 옆 `+` → 표정 이름과 태그 (캐릭터마다 따로)
4. 아래 카드에서 필요 없는 조합을 눌러 빼기 (빈 동그라미 = 안 만듦, 다시 누르면 돌아옴)
5. `대기열에 N개 추가` 또는 `새 대기열로`

칩을 누르면 오른쪽 칸에서 고치고, 아무것도 안 고른 상태에서는 베이스 프롬프트·조합당 장수 같은 공통 설정이 나옵니다.

**이름 규칙** (아래 `이름` 메뉴)

| 고르는 것 | 결과 |
|---|---|
| 캐릭터_표정_배경 (기본) | `김춘자_웃음_교실` |
| 캐릭터_배경_표정 | `김춘자_교실_웃음` |
| 캐릭터_표정 | `김춘자_웃음` — 배경이 여러 개면 이름이 겹친다고 알려 줍니다 |
| 캐릭터-표정-배경 / 띄어쓰기 | `김춘자-웃음-교실` / `김춘자 웃음 교실` |

대기열에는 이름 순서대로 들어가고, 조합으로 만든 항목은 이름 규칙과 상관없이 캐릭터 폴더에 저장됩니다.
예전에 쓰던 조합(코드 이름, `1 hooded eyes` 줄 번호 형식)도 그대로 불러와 `w_h_1` 같은 이름을 유지합니다.

캐릭터 프롬프트는 외형, 표정, 배경 태그를 합쳐 만들고, 그룹 사이 태그가 붙지 않도록 쉼표를 자동으로 보완합니다.

## 저장 위치

기본 저장 폴더는 브라우저 다운로드 폴더 아래의 `NovelAI`입니다.
설정의 **저장 폴더**에서 하위 경로를 변경할 수 있습니다.

그 아래는 설정의 두 스위치로 나뉩니다 (둘 다 기본 켜짐).

| 날짜별 | 캐릭터별 | 저장 이름 `김춘자_교실` | 저장 이름 `교실` |
|---|---|---|---|
| 켬 | 켬 | `NovelAI/2026-10-22/김춘자/` | `NovelAI/2026-10-22/` |
| 켬 | 끔 | `NovelAI/2026-10-22/` | `NovelAI/2026-10-22/` |
| 끔 | 켬 | `NovelAI/김춘자/` | `NovelAI/` |
| 끔 | 끔 | `NovelAI/` | `NovelAI/` |

예시:

```text
NovelAI/프로젝트A
```

같은 파일명이 이미 있으면 Chrome이 번호를 자동으로 덧붙입니다.

## 중지 방법

- 정상 중지: **자동 생성 중지** 또는 **대기열 중지**
- 생성 중 한 번 누르면 현재 생성 중인 이미지까지 저장한 뒤 멈추는 **정지 대기 중** 상태가 됩니다.
- 즉시 중지하려면 중지 버튼을 한 번 더 누릅니다.
- 패널이 접혀 있으면 빨간 정지 표시를 눌러 패널을 펼친 뒤 중지 버튼을 누릅니다.

## 문제 해결

### 오류가 났을 때 (로그 내보내기)

1. 설정 탭 → **문제 진단** → **오류 로그 내보내기**를 누릅니다.
2. 다운로드된 `nai-autosaver-log-….txt` 파일을 그대로 전달합니다.

파일에는 상태 문구 기록, 프롬프트 입력 결과, 예외, 현재 NovelAI 화면 인식 상태가 들어 있습니다. 프롬프트 텍스트 일부(기대값/실제값 비교)가 포함되니 공유 전에 확인하세요.


### 수정본을 설치했는데 예전 동작이 계속됨

1. 기존 확장 프로그램을 끄거나 삭제합니다.
2. 새 폴더를 다시 로드합니다.
3. 확장 프로그램을 새로고침합니다.
4. NovelAI 페이지를 새로고침합니다.

여러 버전을 동시에 켜두면 두 content script가 함께 실행될 수 있습니다.

### 잘못된 캐릭터 카드가 남아 있음

현재 버전은 캐릭터 블록 수에 맞춰 남는 카드를 자동으로 정리합니다. 그래도 이상한 카드가 남아 있으면 휴지통 버튼으로 직접 삭제한 뒤 다시 실행하세요. NovelAI의 UI 상태가 오래 남아 있으면 페이지 새로고침이 필요할 수 있습니다.

### “캐릭터 카드는 생성됐지만 Character N 영역을 찾지 못했습니다”가 표시됨

- NovelAI 이미지 페이지를 새로고침합니다.
- 다른 버전의 NAI 자동저장이 동시에 켜져 있지 않은지 확인합니다.
- Character Prompts 영역이 화면에 생성된 뒤 다시 실행합니다.
- 그래도 반복되면 현재 NovelAI UI 구조가 변경된 경우일 수 있습니다.

### 캐릭터 프롬프트가 Base Prompt에 들어감

v1.0.16 이전 수정 과정에서 발생했던 문제입니다. Base Prompt 끝에 남은 `| 1girl... | 1boy...` 부분을 직접 지우고 v1.0.18로 다시 실행합니다. 현재 버전은 캐릭터 영역을 찾지 못할 경우 Base Prompt로 병합하지 않고 오류를 표시합니다.
