# NAI 자동저장 v1.0.18

NovelAI 이미지 생성 페이지(`https://novelai.net/image`)에서 사용하는 Chrome Manifest V3 확장 프로그램입니다.
자동 생성, 이미지 자동 저장, 대기열, 조합 생성, Base Prompt와 캐릭터 프롬프트 분리 입력을 지원합니다.

## 주요 기능

- **자동 생성**: 지정한 횟수와 주기에 따라 NovelAI의 Generate 버튼을 자동 실행
- **이미지 자동 저장**: 생성이 완료될 때마다 결과 이미지를 자동 다운로드
- **저장 이름 관리**: `1_b_c`를 입력하면 `1_b_c (1).png`, `1_b_c (2).png`처럼 순번을 붙여 저장
- **대기열**: 항목마다 저장 이름, Base Prompt, Base Undesired Content, 캐릭터 프롬프트, 캐릭터 Undesired Content, 생성 횟수를 따로 설정
- **다중 캐릭터**: `;;`로 구분한 캐릭터를 NovelAI의 Character 1, Character 2… 카드에 순서대로 입력
- **캐릭터 카드 자동 생성**: 필요한 수만큼 Add Character를 누르고 Female, Male, Other를 자동 선택
- **조합 생성기**: 캐릭터, 표정, 배경 조합을 자동으로 대기열 항목으로 생성
- **대기열 가져오기/내보내기**: JSON 형식 지원
- **글래스 UI**: 이동, 접기/펴기, 실행 상태 표시 지원

## 설치 및 업데이트

1. ZIP 파일의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. 기존 버전이 켜져 있다면 끄거나 삭제합니다.
5. **압축해제된 확장 프로그램을 로드**를 누릅니다.
6. 압축을 푼 `NAI-AutoSaver-v1.0.18` 폴더를 선택합니다.
7. 확장 프로그램 화면에서 새로고침 버튼을 누른 뒤, NovelAI 이미지 페이지도 새로고침합니다.

> 코드만 교체하고 NovelAI 페이지를 새로고침하지 않으면 이전 content script가 계속 작동할 수 있습니다.

## 기본 사용법

### 자동 생성

1. NovelAI 이미지 페이지를 엽니다.
2. 오른쪽 아래의 NAI 자동저장 패널을 펼칩니다.
3. 저장 이름, 프롬프트, 횟수, 주기를 입력합니다.
4. **자동 생성 시작**을 누릅니다.

`횟수`가 `0`이면 중지할 때까지 계속 생성합니다.

### Base Prompt와 캐릭터 프롬프트

Base Prompt와 캐릭터 프롬프트는 서로 다른 입력칸입니다.

- 장면, 화풍, 품질, 배경 등 공통 태그 → **Base Prompt**
- 인물별 성별, 머리색, 눈색, 의상 등 → **캐릭터 프롬프트**

캐릭터 프롬프트를 Base Prompt에 직접 붙일 필요는 없습니다. 확장 프로그램이 각 Character 카드에 따로 입력합니다.

## 다중 캐릭터 입력법

### 한 명

```text
1girl, black hair, red eyes
```

### 두 명

```text
1girl, black hair, red eyes
;;
1boy, white hair, blue eyes
```

### 세 명

```text
1girl, black hair, red eyes
;;
1boy, white hair, blue eyes
;;
1other, silver hair, green eyes
```

### 구분 규칙

- **한 캐릭터 안의 태그 구분**: 쉼표 `,`
- **캐릭터와 캐릭터 구분**: 쌍세미콜론 `;;`
- 줄바꿈은 선택 사항입니다.
- 화살표 `→`는 입력하지 않습니다.
- 세로줄 `|`도 캐릭터 구분자로 사용하지 않습니다.
- 전각 구분자 `；；`도 인식하지만 일반 `;;` 사용을 권장합니다.

한 줄로 작성해도 됩니다.

```text
1girl, black hair, red eyes ;; 1boy, white hair, blue eyes
```

### 성별 자동 선택

각 `;;` 블록의 성별 태그를 읽어 캐릭터 카드의 유형을 선택합니다.

- `1girl`, `girl`, `female`, `woman` → Female
- `1boy`, `boy`, `male`, `man` → Male
- 성별을 판단할 수 없는 경우 → Other

NovelAI는 Female/Male 카드 생성 후 `1girl` 또는 `1boy`를 화면에서 `girl,` 또는 `boy,`로 정규화해 표시할 수 있습니다. 이는 정상 동작입니다.

캐릭터 카드의 성별이 입력 블록과 다르면, v1.0.18은 첫 불일치 카드부터 뒤쪽 카드를 정리한 뒤 올바른 성별로 다시 생성합니다.

## 캐릭터 Undesired Content

캐릭터 네거티브도 긍정 프롬프트와 같은 순서로 `;;`를 사용합니다.

```text
bad hands, extra fingers
;;
long hair, red eyes
```

- 첫 번째 블록 → Character 1의 Undesired Content
- 두 번째 블록 → Character 2의 Undesired Content
- 비워두면 기존 값을 유지합니다.

## 대기열

1. **현재 프롬프트 추가**를 눌러 현재 설정을 대기열 항목으로 저장합니다.
2. 각 항목에서 다음 값을 개별 편집합니다.
   - 저장 이름
   - Base Prompt
   - Base Undesired Content
   - 캐릭터 프롬프트
   - 캐릭터 Undesired Content
   - 횟수
3. **대기열 실행**을 누르면 항목별 프롬프트를 적용하고 순서대로 생성·저장합니다.
4. 반복을 켜면 마지막 항목 이후 다시 첫 항목부터 실행합니다.

대기열의 저장 이름은 각 항목에 설정된 값이 사용됩니다. 자동 생성 화면의 단발 저장 이름과는 별개입니다.

## 조합 생성

Base Prompt 1개와 캐릭터·표정·배경 세트를 조합해 대기열을 자동 생성합니다.

항목 이름 형식:

```text
캐릭터코드_배경코드_감정번호
```

예시:

```text
w_h_1
```

캐릭터 프롬프트는 외형, 표정, 배경 태그를 합쳐 생성되며, 그룹 사이의 태그가 붙지 않도록 필요한 쉼표를 자동 보완합니다.

## 저장 위치

기본 저장 폴더는 브라우저 다운로드 폴더 아래의 `NovelAI`입니다.
설정의 **저장 폴더**에서 하위 경로를 변경할 수 있습니다.

예시:

```text
NovelAI/프로젝트A
```

같은 파일명이 이미 있으면 Chrome이 번호를 자동으로 덧붙입니다.

## 중지 방법

- 정상 중지: **자동 생성 중지** 또는 **대기열 중지**
- 생성 중 한 번 누르면 현재 생성 중인 이미지까지 저장한 뒤 멈추는 **정지 대기 중** 상태가 됩니다.
- 즉시 중지하려면 중지 버튼을 한 번 더 누릅니다.
- 패널이 접혀 있으면 빨간 정지 표시를 눌러 패널을 펼친 뒤 중지 버튼을 누릅니다.

## 문제 해결

### 수정본을 설치했는데 예전 동작이 계속됨

1. 기존 확장 프로그램을 끄거나 삭제합니다.
2. 새 폴더를 다시 로드합니다.
3. 확장 프로그램을 새로고침합니다.
4. NovelAI 페이지를 새로고침합니다.

여러 버전을 동시에 켜두면 두 content script가 함께 실행될 수 있습니다.

### 잘못된 캐릭터 카드가 남아 있음

이전 버전이 만든 Character 3, Character 4 등의 불필요한 카드는 휴지통 버튼으로 삭제한 뒤 다시 실행하는 것이 가장 확실합니다. v1.0.18도 현재 `;;` 블록 수와 성별에 맞춰 카드를 정리하지만, NovelAI의 UI 상태가 오래 남아 있으면 페이지 새로고침이 필요할 수 있습니다.

### “캐릭터 카드는 생성됐지만 Character N 영역을 찾지 못했습니다”가 표시됨

- NovelAI 이미지 페이지를 새로고침합니다.
- 다른 버전의 NAI 자동저장이 동시에 켜져 있지 않은지 확인합니다.
- Character Prompts 영역이 화면에 생성된 뒤 다시 실행합니다.
- 그래도 반복되면 현재 NovelAI UI 구조가 변경된 경우일 수 있습니다.

### 캐릭터 프롬프트가 Base Prompt에 들어감

v1.0.16 이전 수정 과정에서 발생했던 문제입니다. Base Prompt 끝에 남은 `| 1girl... | 1boy...` 부분을 직접 지우고 v1.0.18로 다시 실행합니다. 현재 버전은 캐릭터 영역을 찾지 못할 경우 Base Prompt로 병합하지 않고 오류를 표시합니다.

## 변경 이력

### v1.0.18

- 비활성 캐릭터 카드를 실제 마우스 클릭처럼 선택한 뒤 편집기를 열도록 수정
- `♀ Female`, `♂ Male`, `⚧ Other`처럼 성별 기호가 포함된 메뉴 항목 인식 보강
- `;;` 블록의 성별과 기존 카드 성별이 다르면 불일치 카드부터 뒤쪽을 삭제하고 올바르게 재생성
- Character 2가 compact 상태일 때 `girl,`만 남고 두 번째 캐릭터 태그가 입력되지 않던 문제 수정

### v1.0.17

- Character Prompts 영역이 Base Prompt 영역 바깥에 렌더링되는 현재 NovelAI 구조 반영
- 문서 전체에서 Character N 헤더를 찾되 확장 프로그램 패널은 제외하도록 수정
- 성별 기호의 variation selector 때문에 Character 헤더를 놓치는 문제 보정
- 카드가 있는데도 Character N 영역을 찾지 못했다고 표시되는 문제 수정

### v1.0.16

- 캐릭터 프롬프트가 Base Prompt에 `|` 형태로 들어가던 잘못된 fallback 제거
- 중첩된 Character N 제목 인식 보강
- 캐릭터 카드 내부 편집기를 카드 범위 안에서만 찾도록 수정
- 캐릭터 영역 탐색 실패 시 Base Prompt에 병합하지 않고 오류 표시

### v1.0.15

- 입력 전 캐릭터 카드를 자동으로 펼치고 Prompt 탭 활성화

### v1.0.14

- 쉼표 단위로 태그를 실제 입력 이벤트처럼 순차 입력
