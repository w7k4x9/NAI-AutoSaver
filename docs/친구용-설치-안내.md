# NAI 자동저장 설치하기 (스토어 승인 전 임시 설치)

웹스토어 승인이 나기 전까지 이렇게 설치해서 쓰면 돼요. 5분이면 끝나요.

## 설치

1. 받은 `NAI-AutoSaver-1.9.4.zip`의 **압축을 풀어요.**
   - 풀린 폴더는 **지우거나 옮기지 말고** 계속 두세요 (지우면 확장 프로그램도 꺼져요).
   - 예: `문서/NAI-AutoSaver` 같은 곳에 두기
2. 크롬 주소창에 `chrome://extensions` 를 치고 들어가요.
3. 오른쪽 위 **개발자 모드**를 켜요.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 1번에서 푼 폴더(안에 `manifest.json`이 있는 폴더)를 골라요.
5. NovelAI 이미지 페이지(`novelai.net/image`)를 열면 오른쪽 아래에 동그란 버튼이 생겨요. 누르면 패널이 열려요.

> 크롬이 가끔 "개발자 모드 확장 프로그램을 사용 중지하세요"라고 물어보는데, **취소**(또는 닫기)를 누르면 계속 쓸 수 있어요.

## 스토어 버전이 나오면

1. 받은 스토어 링크에서 **Chrome에 추가**를 눌러요.
2. NovelAI 페이지를 한 번 열어요. 그러면 예전 버전이 알아서 비켜서고 **"스토어 버전으로 옮겼어요"** 창이 떠요.
3. 그 창에서 **이 예전 버전 지우기**를 누르면 끝이에요.

메모·대기열·설정은 스토어 버전으로 자동으로 넘어가요. 앞으로는 크롬이 알아서 업데이트해요.
