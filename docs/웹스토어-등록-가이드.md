# 크롬 웹스토어 비공개 등록 가이드

목표: 링크를 가진 사람만 설치할 수 있는 "비공개(Unlisted)" 등록 → 이후 새 버전은 **업로드만 하면 모든 사용자에게 자동 업데이트**됩니다.

처음 한 번만 30분 정도 걸리고, 그다음 업데이트는 5분이면 됩니다.

---

## 0. 준비물

- 구글 계정 (2단계 인증 켜져 있어야 함)
- 개발자 등록비 **5달러** (한 번만, 카드 결제)
- `NAI-AutoSaver-1.9.3.zip` (같이 드린 파일 · 압축 풀지 말고 그대로 올림)
- 스크린샷 `스토어-스크린샷-1.png` ~ `5.png` (같이 드린 1280×800 이미지)
- 아이콘: zip 안의 `icons/icon128.png`

## 1. 개발자 등록 (처음 한 번)

1. [Chrome Web Store 개발자 대시보드](https://chrome.google.com/webstore/devconsole) 접속 → 구글 로그인
2. 약관 동의 → 등록비 5달러 결제
3. 계정 설정에서 **연락처 이메일 인증**까지 끝내야 제출 버튼이 활성화됩니다

## 2. 새 항목 올리기

1. 대시보드 → **새 항목(New item)** → `NAI-AutoSaver-1.9.3.zip` 업로드
2. 업로드하면 바로 설치 테스트가 돌아갑니다. 문제가 있으면 이 단계에서 알려 줍니다

## 3. 스토어 등록정보 (Store listing)

| 칸 | 넣을 내용 |
|---|---|
| 설명 | 아래 "설명 문구" 복사 |
| 카테고리 | 도구 (Tools) 또는 작업 흐름 및 계획 |
| 언어 | 한국어 |
| 스토어 아이콘 | `icons/icon128.png` |
| 스크린샷 | `스토어-스크린샷-1.png` ~ `5.png` (순서대로) |

**설명 문구** (복사해서 사용):

```
NovelAI 이미지 생성 페이지를 돕는 비공식 도구입니다. NovelAI와는 관련이 없습니다.

· 자동 생성: 횟수·주기를 정해 생성 버튼을 자동으로 누르고 결과를 저장
· 대기열: 항목마다 프롬프트·캐릭터·네거티브·장수를 따로 설정해 순서대로 생성
· 조합 생성: 캐릭터 × 배경 × 감정 조합을 한 번에 대기열로 (이름 규칙·생성 순서 지정)
· 자동 저장: NovelAI와 같은 WebP·PNG로, 다운로드 폴더 아래 날짜별·캐릭터별 폴더에 정리
· 프롬프트 메모: 휴지통, 자동 임시 저장, 자동 백업 파일로 메모가 사라지지 않게
· 보관함: 저장한 그림을 프롬프트로 검색하고, 메타데이터를 지운 사본·검열 사본을 한 번에
· 태그 뜻: 프롬프트 태그에 마우스를 올리면 한국어 뜻 표시
· 노션 연결(선택): 내 노션 데이터베이스에 그림과 프롬프트를 캐릭터·날짜별로 정리

개발자에게 보내는 데이터는 없습니다. 노션 연결은 사용자가 직접 켠 경우에만 본인의 노션으로 보냅니다.
```

## 4. 개인정보 보호 (Privacy) 탭

**단일 목적 (Single purpose)**

```
NovelAI 이미지 생성 페이지에서 프롬프트 입력·자동 생성·결과 저장을 돕습니다.
```

**권한별 사유** (칸마다 복사):

| 권한 | 사유 |
|---|---|
| downloads | 생성된 이미지와 사용자 데이터 백업 파일을 사용자의 다운로드 폴더(날짜/캐릭터별 하위 폴더)에 저장합니다. |
| storage | 프롬프트 메모, 대기열, 설정을 사용자의 브라우저에 저장합니다. |
| notifications | 대기열/자동 생성이 끝났을 때 완료 알림을 표시합니다. |
| scripting | NovelAI 탭을 새로고침하지 않은 경우 도우미 패널을 다시 연결합니다. |
| offscreen | 시작·완료 알림음을 재생하고, 다른 탭에 있을 때도 생성이 느려지지 않게 합니다. |
| 호스트 권한 (novelai.net) | NovelAI 이미지 생성 페이지에 도우미 패널을 표시하고 프롬프트를 입력합니다. |
| 선택 호스트 권한 (api.notion.com) | 사용자가 직접 노션 연결을 켤 때만 요청합니다. 사용자가 고른 노션 데이터베이스에 그림과 프롬프트를 저장합니다. |

**원격 코드 사용** → "아니요, 원격 코드를 사용하지 않습니다"
(검열 기능이 처음 한 번 내려받는 파일은 실행 코드가 아니라 모델 가중치 **데이터**예요. 실행 엔진 onnxruntime-web은 확장 프로그램 안에 들어 있어요. 심사에서 물어보면 이렇게 설명하면 돼요)

**데이터 사용** → 아래 두 개만 체크
- **웹사이트 콘텐츠**: NovelAI 페이지의 프롬프트와 생성된 그림을 읽고 저장해요
- **인증 정보**: 노션 연결을 켜면 노션 토큰을 이 컴퓨터에 저장해요

나머지(개인 식별·건강·금융·커뮤니케이션·위치·웹 기록·사용자 활동)는 체크하지 않아요.
아래 **세 가지 확인 항목은 모두 체크**해요 (하나라도 빠지면 제출이 안 돼요).

(크롬 웹스토어는 개발자 서버로 보내지 않고 컴퓨터 안에서만 다루는 데이터도 적도록 해요. 그래서 "보내지 않는다"와 별개로 위 두 개는 체크해요. 개발자가 받는 데이터는 여전히 없어요.)

**개인정보처리방침 URL** → GitHub 저장소의 `PRIVACY.md` 주소
(예: `https://github.com/w7k4x9/NAI-AutoSaver/blob/main/PRIVACY.md`)

## 5. 배포 (Distribution) 탭

- **공개 범위: 비공개 / Unlisted (링크가 있는 사람만)** ← 이걸로 고르세요
- 지역: 모든 지역 (또는 대한민국만)
- 가격: 무료

> 화면의 한국어 표기는 바뀔 수 있습니다. "링크가 있는 사람만 볼 수 있음"에 해당하는 항목을 고르면 됩니다.

## 6. 검토 제출

오른쪽 위 **검토를 위해 제출** → 보통 며칠 안에 결과 메일이 옵니다. 거절되면 메일에 이유가 적혀 오니 그대로 보내 주세요.

## 7. 승인 후 옮겨 타기

1. 스토어 페이지 링크로 **설치**
2. NovelAI 이미지 페이지를 열면 아래쪽에 "이전 설치에서 자동으로 가져왔어요: 메모 · 대기열 · 설정" 문구가 뜹니다
   - 이건 1.1.0 이상 압축해제 버전을 **한 번이라도 켠 적이 있어야** 됩니다 (그때부터 NovelAI 페이지 쪽에 사본이 쌓임)
   - 혹시 안 뜨면: 압축해제 버전에서 설정 → 백업 → **전체 백업 내보내기** → 스토어 버전에서 **백업 가져오기**
3. 메모가 다 있는 걸 확인한 뒤 `chrome://extensions` 에서 **예전 압축해제 버전 삭제** (둘 다 켜 두면 패널이 두 개 뜹니다)

## 8. 다음 업데이트 (매번)

1. `manifest.json` 의 `"version"` 숫자를 올림 (예: 1.3.0 → 1.3.1)
2. zip으로 묶어서 대시보드 → 해당 항목 → **패키지 → 새 패키지 업로드**
3. **검토를 위해 제출**
4. 승인되면 끝. 크롬이 몇 시간 안에 알아서 업데이트하고, 메모는 그대로 유지됩니다
